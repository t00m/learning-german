# Feierabend machen

## Variants

- Ich mache heute um vier Feierabend. :: I'm finishing work at four today.
- Schönen Feierabend! :: Enjoy your evening! (after work)

## Usage

*Schönen Feierabend!* is what colleagues say when someone goes home.
