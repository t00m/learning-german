# Viel Spaß!

## Variants

- Viel Spaß beim Feiern! :: Have fun celebrating!
- Viel Erfolg! :: Good luck! (with a task)
- Viel Glück! :: Good luck!

## Usage

*beim* plus a verb as a noun says what to have fun with: *beim Spiel*, *beim Grillen*.
