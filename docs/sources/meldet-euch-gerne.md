# meldet euch gerne

## Variants

- Wenn es Probleme mit der Bezahlung gibt, meldet euch gerne. :: If there are problems with the payment, feel free to get in touch.
- Melde dich gerne, wenn du Fragen hast. :: Get in touch if you have questions.
- Melden Sie sich gerne bei uns. :: Feel free to contact us. (formal)

## Usage

*sich melden* is to get in touch. *gerne* makes it friendly: "you are welcome to". Club messages to parents usually use *ihr*.
