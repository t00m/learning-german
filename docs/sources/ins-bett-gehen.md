# ins Bett gehen

## Variants

- Um acht Uhr gehen die Kinder ins Bett. :: At eight o'clock the children go to bed.
- Zeit fürs Bett! :: Time for bed!

## Usage

*ins* is *in das*: movement, so Akkusativ. In bed is *im Bett*.
