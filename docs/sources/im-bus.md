# Im Bus

- **ich:** Entschuldigung, fährt der Bus zum Bahnhof? :: Excuse me, does the bus go to the station?
- **Busfahrer:** Ja. Steigen Sie ein! :: Yes. Get on!
- **ich:** Eine Fahrkarte, bitte. Was kostet das? :: A ticket, please. How much is it?
- **Busfahrer:** Drei Euro. :: Three euros.
- **ich:** Wo muss ich aussteigen? :: Where do I have to get off?
- **Busfahrer:** An der nächsten Haltestelle. :: At the next stop.
- **ich:** Danke schön! :: Thank you!

## Variations

- 2 **Busfahrer:** Nein, nehmen Sie die Linie vier. :: No, take the number four.

## Notes

A model conversation: written to practise, not one that happened.

*aussteigen* is separable: *Wo steige ich aus?* In the question with *muss* it stays together at the end: *Wo muss ich aussteigen?*
