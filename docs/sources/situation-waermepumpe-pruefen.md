# Wärmepumpe prüfen

## I can

- [ ] Ich kann den Anlagendruck ablesen und Wasser nachfüllen. :: I can read the system pressure and top up water.
- [ ] Ich kann die Heizkörper entlüften. :: I can bleed the radiators.
- [ ] Ich kann der Notfall-Hotline eine Störung beschreiben. :: I can describe a fault to the emergency hotline.
