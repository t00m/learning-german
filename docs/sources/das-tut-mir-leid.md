# Das tut mir leid.

## Variants

- Oh, das tut mir leid! :: Oh, I'm sorry!
- Es tut mir leid, ich bin zu spät. :: I'm sorry, I'm late.

## Usage

When something bad happened, or to apologise. For a small thing, *Entschuldigung!* is enough.
