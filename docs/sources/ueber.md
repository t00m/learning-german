# über

## Examples

- Wir sprechen über den Ausflug. :: We will talk about the trip.
- Das Bild hängt über dem Sofa. :: The picture hangs above the sofa.

## Notes

*über* plus Akkusativ also means *about*: *über den Ausflug sprechen*.
