# Anmeldung

## Examples

- Zur Anmeldung: Der Preis wird per Überweisung bezahlt. :: About registration: the price is paid by bank transfer.
- Die Überweisung gilt als verbindliche Anmeldung. :: The transfer counts as a binding registration.

## Notes

*verbindlich* means binding: once you have signed up, you have to pay.
