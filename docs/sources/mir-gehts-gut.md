# Mir geht's gut.

## Variants

- Gut, danke. Und dir? :: Fine, thanks. And you?
- Es geht. :: So-so.
- Nicht so gut. Ich bin erkältet. :: Not so good. I have a cold.

## Usage

The answer to *Wie geht's?*. *mir* is Dativ: literally *it goes well for me*.
