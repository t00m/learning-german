# alle
## Examples

- Alle sind da. Wir können anfangen. :: Everybody is here. We can start.
- Hallo, alle zusammen! :: Hello, everybody!

## Notes

*alle* is plural: *Alle sind da*. For things, *alles*: *Alles ist gut*.
