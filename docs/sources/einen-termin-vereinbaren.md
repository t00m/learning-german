# einen Termin vereinbaren

## Variants

- Ich möchte einen Termin vereinbaren. :: I would like to make an appointment.
- Ich brauche einen Termin beim Kinderarzt. :: I need an appointment with the paediatrician.

## Usage

On the phone with a practice, the school or an office.
