# laut

## Examples

- Es wird vielleicht ein bisschen laut. :: It might get a bit loud.
- Ich mache die Musik sofort leiser. :: I will turn the music down right away.

## Notes

The opposite is *leise*, quiet: *leiser machen*, to turn down.
