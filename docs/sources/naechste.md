# nächste
## Examples

- Nächste Woche habe ich Urlaub. :: Next week I am on holiday.
- Wir steigen an der nächsten Haltestelle aus. :: We get off at the next stop.

## Notes

It takes adjective endings: *nächste Woche*, *nächsten Montag*, *das nächste Mal*.
