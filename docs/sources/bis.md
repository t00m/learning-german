# bis

## Examples

- Bitte geben Sie den Zettel bis Dienstag zurück. :: Please return the slip by Tuesday.
- Ich muss bis sechs arbeiten. :: I have to work until six.

## Notes

Usually without an article: *bis Montag*, *bis acht Uhr*. With an article it needs *zu*: *bis zum Ende*.
