# Erster Tag im Büro

- **Kollege:** Hallo! Bist du neu hier? :: Hello! Are you new here?
- **ich:** Ja, heute ist mein erster Tag. :: Yes, today is my first day.
- **Kollege:** Herzlich willkommen! Woher kommst du? :: Welcome! Where are you from?
- **ich:** Ich komme aus Spanien. Ich wohne jetzt hier mit meiner Familie. :: I am from Spain. I live here now with my family.
- **Kollege:** Schön! Sprichst du schon gut Deutsch? :: Nice! Do you already speak German well?
- **ich:** Nur ein bisschen. Ich lerne noch. :: Only a little. I am still learning.
- **Kollege:** Kein Problem. Die Küche ist hier links. Möchtest du einen Kaffee? :: No problem. The kitchen is here on the left. Would you like a coffee?
- **ich:** Ja, gern. Danke! :: Yes, please. Thanks!

## Variations

- 6 **ich:** Ja, ein bisschen. Bitte sprich langsam. :: Yes, a little. Please speak slowly.

## Notes

A model conversation: written to practise, not one that happened.

In many offices colleagues say *du* from the first day. When unsure, wait until they use *du* first.
