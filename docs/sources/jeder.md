# jeder

## Examples

- Jeden Dienstag ist Training. :: There is training every Tuesday.
- Jedes Kind bringt eine Flasche Wasser mit. :: Every child brings a bottle of water.

## Notes

Only singular. Endings like *der, die, das*: *jeder, jede, jedes*.
