# alles

## Examples

- Der Trainer schreibt alles in den Chat. :: The coach writes everything in the chat.
- Heute ist alles voll. :: Everything is full today.

## Notes

*alle* means *everybody* or *all*: *Alle Kinder kommen mit.*
