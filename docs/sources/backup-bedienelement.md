# Backup-Bedienelement

## Examples

- Wenn man das Backup-Bedienelement anschließt, erlischt die Garantie. :: If you connect the backup control unit, the warranty expires.

## Notes

*erlöschen* (*erlischt*, *ist erloschen*) is used for rights and contracts that end: *die Garantie erlischt*.
