# mögen

## Examples

- Mein Sohn mag Pizza. :: My son likes pizza.
- Möchtest du auch einen Kaffee? :: Would you like a coffee too?

## Notes

*möchte* (ich möchte, du möchtest, er möchte) is the polite *would like* and is used every day.
