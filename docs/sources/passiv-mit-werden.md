# Passiv mit werden

## Explanation

Club and school messages use the passive when *what happens* matters more than *who does it*: *werden* plus the participle at the end.
With a modal verb, the modal is conjugated and *werden* goes to the end as an infinitive.

- Die Abfahrtszeit wird noch bekannt gegeben. :: The departure time will still be announced.
- Das Spiel wurde verschoben. :: The match was postponed.
- Das Spiel musste verschoben werden. :: The match had to be postponed.

## Simple German

Passiv: *werden* + Partizip. Wichtig ist, was passiert, nicht wer es macht. Mit Modalverb: *muss ... verschoben werden*.

## Typical mistakes

- Das Spiel musste verschoben wird. :: Das Spiel musste verschoben werden.
- Die Zeit wird bekannt geben. :: Die Zeit wird bekannt gegeben.
