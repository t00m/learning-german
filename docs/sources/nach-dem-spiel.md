# Nach dem Spiel

- **ich:** Herzlichen Glückwunsch! Ihr habt gewonnen! :: Congratulations! You won!
- **Kind:** Ja! Ich habe drei Bälle gehalten. :: Yes! I saved three balls.
- **ich:** Ich habe es gesehen. Du warst super! :: I saw it. You were great!
- **Kind:** Aber am Ende war ich sehr müde. :: But at the end I was very tired.
- **ich:** Das glaube ich. Hast du Hunger? :: I believe it. Are you hungry?
- **Kind:** Ja, großen Hunger! Können wir Pizza essen? :: Yes, really hungry! Can we eat pizza?
- **ich:** Okay, heute ist ein besonderer Tag. :: OK, today is a special day.

## Variations

- 1 **ich:** Schade, ihr habt verloren. Aber ihr habt gut gespielt. :: Pity, you lost. But you played well.

## Notes

A model conversation: written to practise, not one that happened.

*Hunger haben*: to be hungry. German uses *haben* here, like Spanish *tener hambre*.
