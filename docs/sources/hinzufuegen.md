# hinzufügen

## Examples

- Bitte fügt mich zur WhatsApp-Gruppe hinzu. :: Please add me to the WhatsApp group.
- Der Trainer hat mich zur Gruppe hinzugefügt. :: The coach added me to the group.

## Typical mistakes

- Bitte hinzufügt mich zur Gruppe. :: Bitte fügt mich zur Gruppe hinzu.

## Notes

*zu* + Dativ for the group: *zur Gruppe* (zu der Gruppe).
