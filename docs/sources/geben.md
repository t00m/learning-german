# geben

## Examples

- Was gibt es zum Frühstück? :: What is there for breakfast?
- Bei Fieber geben Sie ihm den Saft. :: If he has a fever, give him the syrup.

## Notes

*es gibt* plus Akkusativ means *there is* or *there are*.
