# warm

## Examples

- Die Kinder brauchen warme Kleidung. :: The children need warm clothes.
- Von neun bis zwölf Uhr gibt es kein warmes Wasser. :: From nine to twelve there is no hot water.

## Notes

*warmes Wasser* is hot water from the tap.
