# Bleibt sportlich!

## Variants

- Bis dahin, bleibt sportlich! :: Until then, stay sporty!
- Mit sportlichen Grüßen :: With sporting regards

## Usage

A friendly closing in sports clubs, like *Viele Grüße*. *Mit sportlichen Grüßen* is the written, slightly more formal version.
