# Mannschaft

## Examples

- Wir werden die Trofeo Mediterraneo besuchen, mit viel internationaleren Mannschaften. :: We will go to the Trofeo Mediterraneo, with many more international teams.
- Alle teilnehmenden Mannschaften richten ein Spiel aus. :: All participating teams host a match.
- Die andere Mannschaft ist sehr stark. :: The other team is very strong.

## Notes

Feminine because of *-schaft*. In club language you also hear *das Team*.
