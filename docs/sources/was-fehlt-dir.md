# Was fehlt dir?

## Variants

- Was fehlt Ihnen? :: What's wrong with you? (Sie)
- Was hat er denn? :: What's wrong with him?

## Usage

The doctor's question. The answer often uses *wehtun*: *Mein Hals tut weh.*
