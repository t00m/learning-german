# Anlagendruck

## Examples

- Der Anlagendruck sollte zwischen 1,5 und 2 bar liegen. :: The system pressure should be between 1.5 and 2 bar.
- Liegt der Anlagendruck unter 1,5 bar, füllen Sie Wasser nach. :: If the system pressure is below 1.5 bar, top up water.

## Notes

*die Anlage* here is the installation (the heating system). In a letter, *die Anlage* is an enclosure: *in der Anlage finden Sie...*
