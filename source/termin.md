# Termin

## Examples

- Ich brauche heute einen Termin. :: I need an appointment today.
- Mein Sohn hat morgen einen Termin beim Kinderarzt. :: My son has an appointment at the paediatrician's tomorrow.

## Notes

False friend: *Termin* is not a *term*; it is an appointment with a fixed time.
