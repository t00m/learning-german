# verschieben

## Examples

- Somit musste das Spiel verschoben werden. :: So the match had to be postponed.
- Wir verschieben das Training auf Donnerstag. :: We are moving training to Thursday.

## Typical mistakes

- Das Spiel ist verschiebt. :: Das Spiel ist verschoben.

## Notes

*verlegen* is used the same way: *Das Spiel wurde verlegt.* *verschieben auf* + Akkusativ gives the new date.
