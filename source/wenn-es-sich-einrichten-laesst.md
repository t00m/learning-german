# wenn es sich einrichten lässt

## Variants

- Hallo, wenn es sich einrichten lässt, ja. :: Hello, if it can be arranged, yes.
- Ich komme, wenn es sich einrichten lässt. :: I'll come if I can make it work.

## Usage

A polite yes with a condition: you would like it, but you understand it may not always work. *wenn möglich* is shorter.
