# Herzlichen Glückwunsch!

## Variants

- Herzlichen Glückwunsch zum Geburtstag! :: Happy birthday!
- Herzlichen Glückwunsch, ihr habt gewonnen! :: Congratulations, you won!

## Usage

For a birthday, a win or good news.
