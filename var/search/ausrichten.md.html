Examples

  • Am JSG-Tag richten alle teilnehmenden Mannschaften ein Spiel aus. :: On JSG day all participating teams host a match.
  • Kannst du dem Trainer etwas ausrichten? :: Can you pass a message on to the coach?

Notes

Two meanings: to host an event (ein Turnier ausrichten), and to pass on a message (jemandem etwas ausrichten, + Dativ for the person).
